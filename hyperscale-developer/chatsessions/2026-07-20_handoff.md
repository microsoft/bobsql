## Run the app (gotchas that cost time — READ before re-running)

- Use `./presentations/hyperscale-developer/build/run.ps1` (starts + opens your real
  browser; `-OpenOnly`, `-NoBrowser`).
- **Do NOT use VS Code Simple Browser** — rejects dev cert, drops the Blazor circuit.
  `run.ps1` uses `Start-Process` → your default browser.
- **HSTS gotcha**: serve BOTH http+https (`ASPNETCORE_URLS='https://localhost:7170;http://localhost:5170'`),
  because a prior HTTPS run caches HSTS for localhost and upgrades http→https.
- First load is slow (Entra token acquisition), then fast.
- Config: `WardGeneral:Server`/`Database` in `src/WardGeneral.Web/appsettings.json`.

## Deploying SQL to the DB (gotcha)

- `sqlcmd` (ODBC17) `-G` Entra-integrated **fails** with "unknown error" on this machine.
- Use the **VS Code MSSQL extension** (mssql_connect + mssql_run_query, split scripts on `GO`)
  or Azure Data Studio / SSMS. `git` also not on the venv-terminal PATH
  (`C:\Program Files\Git\cmd\git.exe`).
