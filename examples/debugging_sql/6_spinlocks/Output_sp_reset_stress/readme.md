# Captured connection-reset stress output

The `query_*.out` files contain captured output from the reset stress workload
used by the [spinlock lab](../readme.md).

They support interpretation of workload behavior and are not scripts to run.
Follow the parent instructions to reproduce the load, correlate it with DMV
observations, and stop the drivers afterward. Captured runs do not establish
expected performance on another machine. Review logs for sensitive details
before publication.
