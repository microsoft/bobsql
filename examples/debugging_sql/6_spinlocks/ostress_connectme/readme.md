# Captured connection-workload output

The `ConnectionDelay_*.out` files are captured output from the connection
workload in the [spinlock lab](../readme.md).

Use these files as examples of previous driver output, not as executable setup
or a current health assessment. Run the parent's connection workload to obtain
new evidence for your own instance. Review logs for connection details before
sharing or publishing them; keep new run output separate from reference captures.
