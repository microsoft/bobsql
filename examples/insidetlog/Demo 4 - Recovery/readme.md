# Demo 4: Recovery

This area contains the [minimal-logging recovery walkthrough](minimal_logged/readme.md).
Read that walkthrough before running its SQL or manipulating database files.

Use an isolated SQL Server instance, appropriate backup/file permissions, and
the tools required by the walkthrough. Recovery demonstrations can take
databases offline, restore data, or depend on a particular starting state.
Check file paths and preserve a restorable copy of the lab before proceeding.

Return to the [transaction-log collection](../readme.md) for the other topics.
