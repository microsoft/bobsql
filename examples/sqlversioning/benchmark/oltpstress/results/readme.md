# Captured write-stress benchmark results

JSON, text, and [HTML results](oltpstress-results.html) from previous
[write-only benchmark](../readme.md) runs.

The files document a historical test environment, not current instance health
or a performance guarantee. Use the parent setup/runner for new measurements
and preserve its configuration and timing alongside any new output.

Inspect generated logs for sensitive details before publishing. Do not replace
reference captures with unrelated runs without documenting their provenance.
