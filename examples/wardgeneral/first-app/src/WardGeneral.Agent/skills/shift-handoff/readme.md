# Shift-handoff runtime instructions

[SKILL.md](SKILL.md) defines the application workflow: first identify candidate
patients, then prepare a grounded handoff for one selected patient.

It specifies evidence requirements, limits on tool use, request-key reuse,
and explicit approval before saving. Keep those contracts aligned with the
agent tools and the [Agentic AI walkthrough](../../../../../agentic-ai/README.md).

This is a demonstration on synthetic charts, not medical guidance. Review
changes as application behavior changes; do not repurpose the runtime skill
as an unrestricted repository automation skill.
