# Application runtime skills

[shift-handoff](shift-handoff/readme.md) contains the application agent's
instructions for candidate selection and a single-patient handoff.

These files are consumed by the Ward General runtime, not automatically
discovered as VS Code workspace skills. The separate repository skill under
`.github/skills/wardgeneral` guides development and demo execution.

Read [Agentic AI](../../../../agentic-ai/README.md) before changing tool
contracts, grounding rules, or the approval-gated save operation.
