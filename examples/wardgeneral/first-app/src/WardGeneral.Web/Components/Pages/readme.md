# Application pages

Routable views for the [Blazor application](../readme.md):
[Home.razor](Home.razor), [Chart.razor](Chart.razor),
[Research.razor](Research.razor), and error/not-found pages.

Home and Chart are part of the base first-app scenario. Research belongs to
the AI-ready SQL progression and depends on its SQL/configuration prerequisites.
Use the existing repositories and page-context service when changing data
access or assistant grounding.

Run with synthetic data and verify navigation, empty/error states, and feature
flags. These demonstration pages are not a production clinical workflow.
