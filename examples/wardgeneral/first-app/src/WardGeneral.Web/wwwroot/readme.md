# Static web assets

[app.css](app.css), the favicon, and the Ward General logo support the
[web application](../readme.md). [lib](lib/readme.md) contains bundled browser
dependencies.

These files are served to browsers. Do not place credentials, private
configuration, database exports, or sensitive diagnostic output here.
Verify layout and chart/assistant styling in the running application after
changing assets. Preserve third-party attribution for bundled dependencies.
