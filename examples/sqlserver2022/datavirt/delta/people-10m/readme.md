# Delta demonstration dataset

Parquet data files and the associated [Delta log](_delta_log/readme.md) used
by the [Delta data-virtualization example](../readme.md).

This is supporting data, not a runnable application. Follow the parent
walkthrough to configure storage and access. Keep the Parquet files and their
transaction-log metadata together; editing either independently can invalidate
the dataset.

The folder name describes the demonstration dataset, not a newly verified row
count. Review data provenance and publication suitability separately from
source-code secret scanning.
