# Delta transaction-log metadata

Metadata for the [parent Delta dataset](../readme.md), including the JSON
transaction entry and checksum file.

These files describe the dataset's committed state; they are not SQL scripts.
Do not hand-edit, reorder, or remove entries to adapt the example. Follow the
[Delta walkthrough](../../readme.md) and preserve the matching Parquet files.
Review metadata and data together before publishing a dataset.
