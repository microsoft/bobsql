# Present the ZavaHospital demo

Five numbered SQL walkthroughs demonstrate clinical-recommendation building
blocks, the recommendation procedure, procedure calls, doctor-note vector
search, and search calls. Begin with
[01_clinical_recommendation_building_blocks.sql](01_clinical_recommendation_building_blocks.sql)
and follow the numbered sequence.

These scripts assume the database, seeded synthetic data, external models,
embeddings, and indexes from the [build](../build/readme.md) are ready.
Use the [hospital guide](../readme.md) for prerequisites and verification.

The architecture assets support presentation; they do not deploy the system.
Model responses are demo output requiring human review, not clinical advice.
Confirm the lab target and do not send real patient data to model endpoints.
